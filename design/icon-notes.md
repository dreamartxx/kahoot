# Bilgi Arena · Pearl & Gold 3D PWA icon

Created with the built-in Imagegen tool on 2026-10-11. Runtime PNG assets are in `public/icons/`: 192×192 and 512×512 normal icons, a separate 512×512 maskable composition, and the opaque 180×180 Apple touch icon. The application identity (`id`, `start_url`, scope and standalone mode) is unchanged. Icon references use `v=pearl-gold-3d` to refresh browser caches. The install entry and its dialog preview use the same artwork.

The maskable image has more breathing room around all foreground forms. The PWA minimum safe area is a centered circle with radius 40% of image width: https://web.dev/articles/maskable-icon. Apple touch icon configuration: https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html.

Regenerate sizes with `python3 scripts/build-icons.py /path/to/normal-master.png /path/to/maskable-master.png`. With no arguments, the script uses the two checked-in 512px compositions. Resizing does not change the artwork. Original generated masters were also saved in the workspace as `bilgi-arena-icon-3d-master.png` and `bilgi-arena-icon-3d-maskable-master.png`.
